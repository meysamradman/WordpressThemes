# Radman Design Library

کارگاه مستقل و محلی طراحی‌های قابل استفادهٔ مجدد؛ بدون وابستگی به سایت Webtalik.

- اجرا: `Start.cmd` — توقف بدون حذف داده: `Stop.cmd`.
- کتابخانه: http://127.0.0.1:8097 — مدیریت: http://127.0.0.1:8097/wp-admin/
- اطلاعات ورود فقط در `.local-admin.txt` است؛ وارد Git نشود.
- در مدیریت «طراحی‌ها» هر نمونه عنوان، خلاصه، تصویر شاخص، دسته و ماژول پیش‌نمایش دارد. نمونه‌ها صفحهٔ مستقل دارند و فهرست صفحه‌بندی می‌شود.
- دسته‌ها: عنوان صفحه، خدمات، گالری، متن و حرکت، هدر و فوتر. دستهٔ تازه را از مدیریت اضافه کنید.

## مالکیت طراحی

هر طراحی در `radman-library/modules/<slug>/` نگهداری می‌شود و در `inc/modules.php` ثبت می‌شود. فایل `view.php` فقط طراحی را رندر می‌کند؛ نوار کتابخانه بیرون آن است. CSS/JS اختیاری همان ماژول فقط در پیش‌نمایش خودش بارگذاری می‌شود. داده و attachmentهای واقعی نمونه باید از WordPress مصرف شوند. نمونهٔ پایه فقط برای نشان‌دادن این مسیر است؛ طراحی تأییدشدهٔ مشتری محسوب نمی‌شود.

نمونه‌های سکشن، هدر/فوتر، آرشیو/جزئیات نمونه‌کار و موشن متن آماده‌اند؛ فهرست کاربرد، GSAP، داده و مسیرهای انتقال در [کاتالوگ طراحی‌ها](docs/catalog.md) است. پیش‌نمایش هر طرح تمام‌عرض و با اسکرول اصلی صفحه باز می‌شود؛ هدر مشترک حفظ شده و فهرست/صفحهٔ اطلاعات موتور انیمیشن بارگذاری نمی‌کنند. افزونه‌ای لازم نیست.

برای انتقال به مشتری، فقط ماژول انتخاب‌شده، داده و وابستگی‌های مصرف‌شده را با قرارداد پروژهٔ مقصد هماهنگ کنید؛ کل قالب یا دیتابیس کتابخانه را کپی نکنید. GSAP محلی مشترک است و فقط نمونه‌های مصرف‌کننده آن را می‌گیرند.

فونت‌های محلی Peyda/Hafez از نسخهٔ موجود Corporate-Webtalik کپی شده‌اند؛ حق استفادهٔ آن‌ها مطابق مجوز اصلی باقی است. وردپرس و دیتابیس داخل volumeهای مستقل Docker هستند؛ سورس قالب در همین فولدر است. ایمیل، HTTP خارجی، به‌روزرسانی خودکار و ایندکس موتور جستجو در محیط محلی غیرفعال‌اند.

سناریوی مرجع، دسته‌بندی و روش برداشت برای مشتری: [docs/scenario.md](docs/scenario.md). فهرست با AJAX و loading سبک کار می‌کند؛ بدون JS لینک‌ها و فرم بومی حفظ می‌شوند.
