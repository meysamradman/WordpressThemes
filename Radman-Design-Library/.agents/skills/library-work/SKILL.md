Read root AGENTS and the relevant section of docs/scenario.md. Use docs/architecture.md for owners, docs/naming.md for identifiers and docs/catalog.md for the requested sample; do not preload every document or skill.

- This is the permanent master library, independent from customer sites. Three native facets are rdl_group (family), rdl_kind (section/page/kit), rdl_fx (technology/effect). Hero, carousel/slider and marquee differ. Blog, music and product catalog have independent archive/detail owners; empty sidebar/carousel categories remain future capacity.
- Each module owns view/data/style/script as needed, with explicit slug, group, kind, effects and provenance in inc/samples.json. Different designs are separate modules. Named page compositions may import selected sections; do not build a settings/variant framework.
- Independence means no unrelated design dependency. Reuse small real owners: fonts/tokens, button/icon renderer, GSAP, lifecycle, scroll state/observers/refresh. Never ship one GSAP copy per sample. docs/module-map.json identifies source files, helper contracts and workshop-only adapters; regenerate it after dependency changes.
- Custom frontend is PHP + Vanilla JS + local GSAP, no Elementor/jQuery/CDN dependency. Native WordPress admin media APIs retain their own dependencies. Use native data APIs, escaped output, password/privacy guards, nonce/capability for writes and local attachment dimensions/srcset.
- The shell and new designs use short rdl- names; imported Radman code retains consistent rdc-/RadmanCT contracts. Apply identifiers across PHP/CSS/JS/dataset/ARIA together. Preserve stored keys, WordPress/GSAP names, slugs and dynamic renderer values; no aliases or runtime renamers.
- Default preview is full width in the current document, with the compact shared library header and original gutters. Keep header/main inside relative scroll content from first paint; no iframe, delayed header correction or second smoother. Info uses ?rdl_info=1 and loads no sample runtime. Keep FAQ/intentional content widths.
- The explicitly requested device tool is the exception: rdl_view laptop/tablet/mobile uses one same-origin canvas iframe; the free default remains direct. Only the inner document loads the design, with client-base and no workshop header. Resize the existing frame, preserve URL/back fallback and exclude all preview controls from selected client builds.
- Retain smooth 1.6 and selected easing, durations, scrub, pin/resize cleanup. Hafez only H1, Peyda other text. Preserve Persian word shaping; start/viewport/fill are separate text behaviors. Do not split Persian into letters. Mobile/reduced-motion remain readable and keyboard usable.
- Catalogue AJAX enhances native forms/links only: combine category/content search, stable paginated ordering, debounce, abort stale requests, small aria-live loading, preserve focus/URL/history and full-page fallback. Keep one design search and one category tree; do not add a second category-search field or duplicate filter controls. Do not load sample GSAP on catalogue/info pages.
- Catalogue palette/cards belong to assets/shell.css only. Use native CSS sticky for its desktop sidebar, account for the WordPress admin bar, allow tall categories to scroll internally and restore normal flow on mobile; no GSAP/pin/scroll listeners for workshop chrome.
- Looping media needs pause control, offscreen/hidden-tab/focus pause and clone/listener/tween cleanup. Localize referenced assets explicitly with provenance, never runtime downloads. Inspect actual reference behavior before implementation; adapt vendor-specific markup without importing its whole plugin stack.
- Native project archive/details, gallery and prev/next/related reuse current Radman owners. Preserve main query after demo rendering; new project records are independent workshop data. Other content types get their own explicit owner when requested.
- npm run build builds the library. --modules=slug,slug creates dist-selected with client-base.css and reachable assets, without changing active dist. Port only chosen PHP/data/media and helper contracts; reuse existing destination helpers once. Selection output is not an installer. Keep workshop toolbar, fixture glue and demo spacing out of client pages.
- Local Docker radman-design-library / 8097 only. Never change webtalik volumes/data or reset either database. Start/Stop preserve data. No automatic resync/import, commit, release, deploy or external tracking. Preserve library edits before explicit source sync.
- Keep docs/scenario/skill concise and current; no routine reports. Run short affected PHP/build/route/asset checks and one bounded browser scenario for a requested visual/behavior change. No long tests, repeated benchmarks, extra browser tooling or FPS claims from throttled automation. Stop checking when the change is answered.

Scope: keep existing home/services sections, but do not add full home/services pages or a kit composition without an explicit request. Current full-page work is archive/detail layouts. Do not expand examples into unrelated pages.

Content carousels compose inc/ui/carousel.php and src/css/ui + src/js/ui/carousel owners. Keep card markup/data in each consuming module; the engine knows no card types. Preserve logical start gutter/opposite edge peek, RTL/LTR keyboard and native touch/drag, resize and lifecycle cleanup. Do not substitute marquee or add a slider framework; see docs/carousel.md.

Carousel arrows advance one card, never a viewport. Keep matching start/end gutters in bleed layouts and avoid double gutters in boxed layouts. Programmatic motion temporarily disables native snap, supports interruption/rapid clicks/reduced motion and restores snap on cleanup; unchanged resize notifications must not cancel it.

Catalog: inc/catalog.php and inc/catalog/ own radman_product, four product taxonomies and the retained _radman_content_data schema adapted from Corporate-Elementor-Catalog. No Elementor, Components/Content plugin, settings panel, cart or checkout dependency. Per-product media/specification fields are native content, not global settings. Transfer catalog modules and their mapped helpers only; do not modify the source checkout or copy its database.

Classify and name designs by their reusable form/behavior (hero, page-title, panels, showcase, accordion, gallery, text), not by the source home/services page. Keep source slugs for stable URLs. Text-fill must initialize every word uniformly, preserve Persian shaping and bind its range to the visible text; clamp the end to reachable scroll and refresh through the existing owner after font layout. Do not add blank runway or a pin to conceal an unreachable range.

Image/card accordions are separate modules with separate data filters; share only the small accordion interaction/geometry owner. Match inspected hover ratios/reset/timing, preserve touch/keyboard/static-mobile/reduced-motion fallbacks and reference media provenance. Never classify a hover accordion as carousel or scroll animation.

Reference sections: column-gallery owns only its three smoother effects and native fallback; media-stretch uses one reachable responsive pin; sticky-cards consumes initializeSticky rather than a second pin system. text-marquee has one accessible group and one inert clone with pause/visibility/focus guards. Keep each design/data filter independent, preserve source motion values in docs/reference-sections.md and do not copy a vendor global kill-all cleanup.

Catalogue cards use a subject-specific local SVG from samples.json/icon, never demo photographs. TextLoop and TextMarquee compose one inc/ui + src/css/ui + src/js/ui text-marquee owner; do not duplicate or import sibling modules. Story/image scroll ranges must stay positive and reachable above the fold; animate media against a fixed anchor. Persian sticky cards keep copy right, images left and the header gutter. Each card owns a 15px rail dot with a 5px center, 25px below its top; dots scroll with cards, never with the pinned heading or a progress tween.

All design display titles use the design name plus " · Radman". Keep reference-site names only in attribution/provenance, not catalogue cards, admin titles or preview headers. Preserve stored slugs and source URLs.

Interactive 3D uses a local Three.js + GLB module, never a substituted Spline/React runtime. Load the viewer only near its consuming preview; render on demand, stop offscreen/hidden, cancel pending loads and dispose GPU/listeners on teardown. Keep poster fallback for reduced motion/coarse pointer/failure. Model provenance and prototype/final status must be explicit; see docs/robot.md. Transfer the module's GLB/poster as well as selected build files; no shared renderer framework without actual repeated use.

Text 3D entrance has two decorative visual faces but one accessible text, preserves Persian words, and uses a separate wrapper for optional pointer motion. Sticky-card rail dots belong to individual cards, not the pinned heading; keep the rail and dots aligned with the same scoped gutter. Record inspected motion values in docs/reference-sections.md.

Design-library/client boundary: the library is the reusable reference; Webtalik is an independent customer implementation. Transfer only selected modules, remap media and inspect all consumers; no automatic cross-project sync or replacement of unrelated page imagery. For marquee comparisons, match pixels per second rather than copying a duration across different card counts; verify acceleration and deceleration separately.
