# Corporate Music

وردپرس مستقل برای آماده‌سازی سایت مشتری موسیقی، بر پایهٔ Radman CT و ماژول‌های منتخب وبلاگ/موسیقی کتابخانه.

- سایت: http://127.0.0.1:8098/
- مدیریت: http://127.0.0.1:8098/wp-admin/
- ورود: نام کاربری و رمز خام در `.env.local-wordpress` با کلیدهای `MUSIC_ADMIN_USER` و `MUSIC_ADMIN_PASSWORD`؛ خلاصهٔ دسترسی هم در `.local-admin.txt` (هر دو خارج از Git)
- روشن/خاموش: `Start.cmd` / `Stop.cmd`؛ داده‌ها و رمزها حفظ می‌شوند.
- ساخت CSS/JS: `npm ci` و سپس `npm run build`؛ روی هاست Node لازم نیست.
- مسیرها: `/music/`، جزئیات آهنگ، `/blog/`، جزئیات مقاله، `/about-us/` و `/contact-us/`.
- Yoast SEO فعال است؛ فونت/رنگ/گردی و اجزای پایه مشترک‌اند و دارایی‌های موسیقی/وبلاگ شرطی بارگذاری می‌شوند.
- اطلاعات مشتری و محتوا فعلاً نمایشی‌اند. فایل صوتی موجود یک تست ساخته‌شدهٔ هشت‌ثانیه‌ای است، نه آهنگ نهایی مشتری.

این پروژه دیتابیس، حساب‌ها و رسانهٔ مستقل دارد. هیچ commit، انتشار یا انتقال به سرور انجام نشده است. قراردادهای معماری و انتقال بعدی در `docs/architecture.md` هستند. ذخیرهٔ Git فقط با دستور صریح و ابزار پروژه‌محور ریشه انجام می‌شود.
