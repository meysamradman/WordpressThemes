# رندر محتوای Elementor

صفحات، وبلاگ، محصول و نمونه‌کار دیگر انتخاب‌گر طراحی PHP/Elementor ندارند. `inc/renderers.php` موقعیت تکی یا آرشیو را از query اصلی WordPress تعیین می‌کند و در صورت وجود قالب منطبق، موقعیت Theme Builder المنتور را رندر می‌کند. شرط‌های ذخیره‌شدهٔ المنتور مالک انتخاب قالب‌اند؛ دادهٔ ویجت یا condition بازنویسی نمی‌شود.

برای محتوای خود برگه، `the_content()` مسیر اصلی است. موقعیت‌های تکی/آرشیو به Elementor Pro نیاز دارند. در نبود Pro یا قالب منطبق، تنها محتوای بومی/پیوند نتایج با صفحه‌بندی نمایش داده می‌شود؛ طرح PHP موازی وجود ندارد. خروجی نوشتهٔ رمزدار از رندر قالب سفارشی عبور نمی‌کند و فرم بومی WordPress حفظ می‌شود.

هدر و فوتر همچنان از سازندهٔ بومی Radman استفاده می‌کنند؛ routing محتوا آن‌ها را تغییر نمی‌دهد. Canvas خود المنتور عمداً بدون پوسته است. تنظیمات قدیمی renderer در دیتابیس اجرا نمی‌شوند و حذف نوشته، رسانه، CPT، meta یا قالب المنتور جزو این تبدیل نیست.
