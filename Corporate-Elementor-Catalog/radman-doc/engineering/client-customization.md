# طراحی سایت مشتری

در این محصول، طراحی محتوا با Elementor و کتابخانهٔ Radman Components انجام می‌شود. بستهٔ Child، صفحهٔ PHP مخصوص مشتری و رجیستری طرح PHP همراه محصول نیست. برای تکی و آرشیو از Elementor Pro Theme Builder استفاده کنید؛ هدر و فوترساز خود رادمان مستقل باقی می‌ماند.

تنظیمات عمومی، فونت محلی، کتابخانه، Classic/V3 و Atomic حفظ می‌شوند. توسعهٔ خود ویجت‌ها و سازنده همچنان PHP/CSS/JS است؛ این کد زیرساخت با مسیر حذف‌شدهٔ طرح مشتری تفاوت دارد. نسخهٔ سایت‌های کدنویسی‌شده در Corporate-Webtalik و پروژه‌های مستقل آن نگهداری می‌شود.
