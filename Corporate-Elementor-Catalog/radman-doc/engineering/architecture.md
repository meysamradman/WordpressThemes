# معماری نسخهٔ المنتوری Radman

## مرز محصول

این نسخه فقط مسیر طراحی محتوای Elementor را ارائه می‌کند؛ طرح PHP مخصوص مشتری، انتخاب‌گر custom/elementor و بستهٔ Child ندارد. PHP رندر سمت سرورِ پوسته، سازنده و ویجت‌ها حذف نمی‌شود. شناسه‌های ذخیره‌شده و API کتابخانهٔ کامپوننت‌ها ثابت می‌مانند. Classic/V3 و Atomic هر دو حفظ می‌شوند؛ تبدیل خودکار داده انجام نمی‌شود.

## مالکیت

- Theme در `radmanct/`: پوسته، تنظیمات عمومی، فونت و tokens، هدر/فوترساز بومی، navigation، افکت‌ها و adapterهای المنتور.
- Components: رندر و schema مشترک، ابزارها، کتابخانه و ویجت‌های Classic/Atomic. رندر PHP داخلی یک موتور است؛ حذف مسیر سایت سفارشی به معنای حذف این موتور نیست.
- Content: داده و API اختیاری کاتالوگ/نمونه‌کار. WordPress مالک نوشته و رسانه است. داده‌های قدیمی حذف نمی‌شوند.
- MCP: اتصال اختیاری عامل. `shared/` فقط منبع بیلد مشترک است.

## رندر

صفحات از `the_content()` و المنتور استفاده می‌کنند. تکی و آرشیو، از جمله وبلاگ/محصول/نمونه‌کار، قالب منطبق Theme Builder را مصرف می‌کنند. برای این قالب‌ها Elementor Pro لازم است. نبود قالب منطبق به خروجی پایهٔ بومی و امن وردپرس منتهی می‌شود، نه طراحی PHP جایگزین. صفحهٔ رمزدار ابتدا مرز بومی وردپرس را رعایت می‌کند.

هدر/فوترساز رادمان، انتخاب زبان/برگه/سایت، کتابخانه، ذخیره و پیش‌نمایش آن مستقل و حفظ شده است. Theme Builder المنتور در فرانت هدر و فوتر را تصاحب نمی‌کند. Canvas مطابق رفتار خود المنتور بدون پوسته است. [قرارداد سازنده](builder.md) و [رندر](renderers.md).

## دارایی و اجرا

Vanilla JS عمومی، React از `wp-element` فقط در مدیریت مجاز، GSAP محلی و انتخابی، Vite برای خروجی مصرفی `dist/`. Node روی هاست لازم نیست. ورودی و فایل مخصوص صفحات PHP مشتری در خروجی وجود ندارد؛ CSS/JS مشترک سازنده و ویجت‌ها حفظ می‌شود. هیچ منبع CDN، فونت خارجی یا دانلود در زمان اجرا افزوده نمی‌شود. RTL/LTR، تصویر با ابعاد ذاتی، کاهش حرکت و cleanup رعایت می‌شود.

فونت و رنگ‌ها یک مالک دارند. کنترل المنتور از UI بومی خودش استفاده می‌کند. [دارایی‌ها](assets.md)، [کامپوننت‌ها](components.md)، [نام‌گذاری](naming.md).

## داده و امنیت

API بومی WordPress، MySQL یا MariaDB با پشتیبانی نسخهٔ هدف WordPress؛ اتصال مجزای دیتابیس، SQL وابسته به موتور، پیشوند ثابت یا تبدیل خودکار دیتابیس وجود ندارد. capability و nonce برای نوشتن، validation و escaping، مرز private/password و شناسه‌های ذخیره‌شده حفظ می‌شوند. [امنیت](../scenarios/security-access.md).

محیط محلی `radman-local`، آدرس `127.0.0.1:8094` و volumeهای موجود مستقل‌اند. Start/Stop ریست نمی‌کند. بسته‌های منبع `1.1.1` می‌مانند؛ ZIP، انتشار، انتقال سرور و تغییر نام گسترده تنها با درخواست صریح. بررسی کوتاه source/build به معنای تأیید مرورگر، همهٔ نسخه‌ها یا محیط واقعی مشتری نیست.
