# خلاصه پروژه رادمان المنتور

این پروژه نسخهٔ المنتوری Radman است. طراحی محتوای صفحات در Elementor و قالب‌های تکی/آرشیو در Elementor Pro Theme Builder انجام می‌شود. مسیر طرح‌های سفارشی PHP مشتری و Child همراه محصول حذف شده است. کد PHP داخلی ویجت‌ها، افزونه‌ها و سازنده‌ها همچنان بخش ضروری محصول است.

هدر و فوترساز بومی رادمان، چیدمان‌ها و تخصیص‌های ذخیره‌شده، تنظیمات عمومی، فونت‌های محلی، افکت‌ها و کتابخانهٔ کامپوننت‌ها حفظ می‌شوند. Theme Builder المنتور مالک هدر/فوتر این قالب نیست. حالت Canvas خود المنتور عمداً پوستهٔ سایت را کنار می‌گذارد.

| مسیر | مالکیت |
|---|---|
| `radmanct/` | پوسته، هدر/فوترساز، تنظیمات عمومی و اتصال المنتور |
| `radmanct-components/` | کتابخانه، رندر مشترک و ویجت‌های Classic/V3 و Atomic |
| `radmanct-content/` | داده و API اختیاری محصولات و نمونه‌کار؛ مستقل از طراحی |
| `radmanct-mcp/` | اتصال اختیاری عامل |
| `shared/` | منبع مشترک زمان بیلد؛ روی هاست لازم نیست |

شناسه‌های بسته‌ها، ویجت‌ها، داده‌ها و پیشوند اجرایی `rdct-` حفظ شده‌اند؛ تغییر نام به `rde-` درخواست جداگانه می‌خواهد. منابع محلی‌اند، Node فقط ابزار توسعه است و هاست به Node نیاز ندارد. WooCommerce و پرداخت خارج از محدوده‌اند.

محیط محلی مستقل `radman-local` در `127.0.0.1:8094` است. Start/Stop داده و رمزها را حفظ می‌کند. [معماری](../engineering/architecture.md)، [رندر محتوا](../engineering/renderers.md) و [سازنده](../engineering/builder.md) مرجع قراردادند. هیچ مهاجرت خودکار محتوای المنتور یا حذف نوشته/رسانه مجاز نیست.
