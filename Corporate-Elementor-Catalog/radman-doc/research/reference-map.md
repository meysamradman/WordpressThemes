# مسیر سریع مراجع محلی

نظرات مشتریان — ۲۰۲۶-۱۰-۲۶: `themes/hub-elementor-addons/elementor/params/testimonials.php` برای ترتیب/ترکیب ۱۹ preset، `widgets/testimonial.php` برای metadata و `assets/css/elements/testimonial/` برای هندسهٔ bubble/portrait/stripe/shadow به‌صورت محدود خوانده شدند. ۱۹ چیدمان ساختاری با PHP مشترک و CSS مستقل بازپیاده‌سازی شدند؛ framework، تصاویر و CSS مرجع کپی نشدند. [نگاشت و حدود](../engineering/carousel.md).

Image accordion — ۲۰۲۶-۱۰-۲۶: [Elementra Digital Agency](https://digital-agency.elementra.themerex.net/) برای ساختار تصویر، caption زیر آن و transition flex بررسی شد؛ مدل مستقل خانوادهٔ Curtain با GSAP محلی در [قرارداد کامپوننت‌ها](../engineering/components.md#image-accordion) ثبت است. سورس/framework/تصاویر مرجع منتقل نشدند.

درخواست مالک محصول: برای ساخت هر قابلیت، ابتدا بخش مرتبط نمونه‌های محلی بررسی و الگوی مناسب به‌صورت بهینه و ماژولار برای رادمان استفاده شود. این فهرست مسیر‌یاب است؛ خواندن همهٔ قالب‌ها در هر نوبت لازم نیست. سناریوی رادمان مرجع رفتار است و وجود یک قابلیت در نمونه، آن را خودکار وارد دامنه نمی‌کند.
