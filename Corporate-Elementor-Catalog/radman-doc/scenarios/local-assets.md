# JavaScript، GSAP و منابع محلی

## نسخهٔ ثابت دورهٔ تکمیل — CONFIRMED، ۲۰۲۶-۱۰-۲۸

به درخواست مالک، نسخهٔ سورس Theme، Child Theme، Components، Content و MCP روی **1.1.1** یکسان و تا تکمیل قالب ثابت بماند. تغییرات روزمرهٔ لوکال مجوز افزایش نسخه یا ساخت ZIP نیستند؛ PHP از سورس مشترک و CSS/JS پس از build و Refresh مصرف می‌شوند. hash فایل‌های خروجی همچنان با محتوا تغییر کند تا ثابت‌بودن نسخه باعث cache قدیمی نشود. تغییر بعدی نسخه یا تهیهٔ بستهٔ انتقال/انتشار با دستور صریح مالک است. این تصمیم نسخهٔ WordPress، Elementor، وابستگی‌ها یا شمارهٔ migration/schemaهای داخلی را تغییر نمی‌دهد. ZIPهای قدیمی به‌عنوان بستهٔ 1.1.1 معرفی نشوند؛ صرف تغییر header، بستهٔ تازه نمی‌سازد. [محیط کار اصلی مشترک](../engineering/local-development.md).

**تأکید مالک — CONFIRMED، ۲۰۲۶-۱۰-۲۶:** افکت‌های چندمرحله‌ای پنل مستقل از محتوا با GSAP محلی مشترک پروژه اجرا شوند؛ کد/سبک افکت‌ها شرطی باشد و framework سایت مرجع یا GSAP دوم وارد نشود. حرکت سادهٔ CSS، مجوز اضافه‌کردن موتور موازی برای این افکت‌های پنل نیست. namespace استاندارد SVG یعنی `http://www.w3.org/2000/svg` در `createElementNS` اتصال شبکه یا دانلود محسوب نمی‌شود و نباید با آدرس محلی/HTTPS جایگزین شود. هر URL اجراییِ دریافت فایل همچنان تابع منع اتصال خارجی است. [مالک پیاده‌سازی پنل](../engineering/navigation.md).

## تأییدشده

### استقلال کامپوننت و سبک — CONFIRMED، ۲۰۲۶-۱۰-۲۵

تمام کامپوننت‌های موجود و بعدی باید بر اساس کاربرد و مالکیت ماژولار باشند. مشترک‌بودن امکانات، مجوز ریختن همهٔ rendererها، CSSها، JSها و سبک‌ها در یک بستهٔ عمومیِ اجباری نیست. صفحه‌ای که فقط یک کامپوننت یا یک سبک را مصرف می‌کند، منابع اختصاصی بقیه را دریافت نکند؛ مثلاً از ده سبک یک کامپوننت فقط پایهٔ واقعاً مشترک و سبک انتخاب‌شده بارگذاری شود. منابع چند نمونهٔ هم‌سبک یک‌بار مصرف شوند و دو سبک واقعاً حاضر در صفحه بتوانند کنار هم مستقل کار کنند.

کاربردهای لوگو، اسلایدر بزرگ، کارت، مارکوئی، کارت لایه‌ای و نظرات مشتریان در رابط درج از هم جدا باشند؛ زیرساخت مشترک کوچک، renderer و کنترل مشترک طبق [سناریوی کامپوننت‌ها](components.md) حفظ شوند. همین قاعده برای کامپوننت‌های دیگر نیز لازم است؛ بررسی به کاروسل محدود نیست. CSS و JS مدیریت/preview به سایت عمومی وارد نشوند. کامپوننت ثابت صرفاً به دلیل وجود حالت متحرک در خانوادهٔ خود، موتور حرکت دریافت نکند.

فولدر‌بندی باید روشن، قابل گسترش و متناسب با اندازهٔ واقعی هر ماژول باشد. فایل یا پوشهٔ خالی PHP/CSS/JS و موتور تکراری برای یکدست‌کردن ظاهری درخت لازم نیست؛ برای رفتار ثابت CSS، JavaScript اختصاصی ساخته نشود. معیار سبکی، فایل‌های ساخته‌شده و واقعاً دریافت/اجراشده است، نه تعداد پوشه‌ها. [مالک ساختار، اشتراک و بارگذاری](../engineering/assets.md) قرارداد فنی و شواهد هر اصلاح را نگه می‌دارد.

**قرارداد قطعی نسخه و خروجی — ۲۰۲۶-۱۰-۲۱:** سورس اختصاصی قالب و افزونه‌ها Vanilla JavaScript مدرن با ES2022+ و ES Modules باشد؛ خروجی Production با Vite، هدف `es2020` و minify ساخته شود. React فقط در مرز مدیریتی تأییدشده باقی می‌ماند. از API استاندارد مرورگر و import شرطی استفاده شود؛ هدف syntax به معنی polyfill خودکار یا تضمین همهٔ مرورگرها نیست. سازگاری مرورگر و عملکرد موبایل باید با شواهد مستقل ثبت شود.

نسخهٔ مصوب GSAP دقیقاً **3.15.0** است: `package.json` مقدار `"gsap": "3.15.0"` بدون `^` یا `~` داشته باشد و `package-lock.json` همان نسخه را قفل کند. core و plugin موردنیاز مانند ScrollTrigger از همان پکیج npm و با Vite محلی بسته‌بندی شوند؛ دریافت CDN، وابستگی jQuery یا دانلود زمان نصب/اجرای مشتری مجاز نیست. GSAP فقط پس از نیاز واقعی صفحه/کامپوننت import شود؛ وجود entry در dist مجوز enqueue عمومی آن نیست. ارتقای نسخه نیازمند تصمیم صریح بعدی، تغییر lockfile و بررسی کوتاه مرتبط است. [روش رسمی نصب و ES Modules](https://gsap.com/docs/v3/Installation/).

**تأکید مالک — ۲۰۲۶-۱۰-۲۱:** قرارداد minified و بارگذاری شرطی برای کل قالب، افزونه‌های خود محصول، ماژول‌ها و کامپوننت‌ها الزامی است؛ فقط استایل/رفتار واقعاً استفاده‌شده دریافت شود. نسخهٔ خوانا برای توسعه مجاز است و سایت نباید هر دو نسخه را بخواند. [قرارداد خروجی](compatibility.md)، [مالکیت فایل‌ها و انتخاب variant](../engineering/assets.md) و [جهت زبان](languages.md) مرجع واحد این قواعدند.

**تصمیم نهایی مالک — ۲۰۲۶-۱۰-۲۱:** JavaScript اختصاصی فرانت Vanilla JS مدرن و ES modules باشد؛ منوی موبایل/مگا‌منو، تب، آکاردئون و مودال با همان استک ساخته شوند. حرکت ساده CSS و حرکت پیشرفته GSAP محلی و شرطی باشد. React فقط برای رابط مدیریت و Builderهای پیچیده استفاده شود؛ استثنای قدیمی React عمومی کنار گذاشته شد.

کد اختصاصی رادمان، شامل پل‌های integration، jQuery مصرف یا آن را dependency مستقیم تعریف نکند. این سیاست به معنی حذف jQuery از کل سایت نیست: نسخهٔ ثبت‌شدهٔ هسته deregister/dequeue/غیرفعال یا با نسخهٔ دیگر/CDN جایگزین نشود. WordPress باید بتواند برای Elementor، مدیریت یا افزونهٔ مشتری که dependency دارد، jQuery خود را طبق ترتیب استاندارد بارگذاری کند. صرف وجود jQuery در Network سایت شاهد وابستگی فرانت رادمان نیست. مجوز قبلی استفادهٔ مستقیم در bridge اختصاصی با این تصمیم بسته شد؛ وضعیت اصلاح کد در سند دارایی‌ها مشخص است. [مبنای رسمی مدیریت dependency](https://developer.wordpress.org/reference/functions/wp_enqueue_script/).

ماژول‌ها پس از marker/شرط نیاز با import محلی وارد شوند؛ dependency مشترک یک بار مصرف شود، editor/admin با عمومی مخلوط نشود، listener/observer/timeline با تغییر صفحه یا حذف عنصر پاک شوند. async/defer نباید ترتیب dependencyها را بشکند؛ اسکریپت inline پیکربندی پیش از مصرف‌کننده و اسکریپت وابسته پس از dependency ثبت شود.

**اصلاح مالک — ۲۰۲۶-۱۰-۲۰:** دارایی‌های محصول متمرکز و بر اساس مالکیت ماژول مرتب باشند؛ تصویرها در مسیرهای هم‌معنای `assets` و `images` پراکنده نشوند. قرارداد مسیر و تغییر فایل‌ها در [ساختار دارایی‌ها](../engineering/assets.md) است؛ پوشه‌بندی منابع با تفکیک مدیریت/عمومی و بارگذاری شرطی همراه باشد.

- JavaScript قالب ماژولار، بهینه و با مالک مشخص باشد؛ فایل بزرگ عمومی شامل همه امکانات یا کتابخانه تکراری تحمیل نشود.
- GSAP + ScrollTrigger جزو قابلیت‌های انیمیشن اختیاری رادمان باشند و همراه قالب به‌صورت محلی ارائه شوند؛ وابسته به دریافت از CDN نباشند.
- فایل‌های لازم خود قالب، شامل JS، CSS، فونت، آیکون، تصویر و افزونه‌های لازم GSAP از همان سایت ارائه شوند. قالب برای کارکرد عادی اتصال خارجی ایجاد نکند.
- هیچ CDN، Google Fonts، tracker، telemetry، دریافت کتابخانه از راه دور یا fallback خارجی مخفی در قالب نباشد؛ وابستگی‌های گذرا نیز بررسی شوند.

داشتن GSAP داخل بسته به معنی دانلود و اجرای آن در تمام صفحات نیست؛ فقط صفحه/بخش نیازمند انیمیشن فایل‌های لازم را بگیرد. قرارداد جداسازی فایل‌های مدیریت و عمومی و CSS minified در [سازگاری](compatibility.md) است.

## مرز اتصال خارجی

**CONFIRMED — اصلاح مالک محصول:** خود رادمان فعلاً هیچ سیستم فعال‌سازی/اعتبارسنجی لایسنس، تماس با سرور لایسنس یا قفل امکانات ندارد. اتصال اختیاری آیندهٔ ابزارهای Claude/Codex فقط طبق [سناریوی MCP](ai-mcp.md) بررسی می‌شود؛ این اتصال برای اجرا، نمایش صفحات، منابع محلی یا فعال‌سازی قالب لازم نیست و مجوز اتصال عمومی به سرویس‌های خارجی محسوب نمی‌شود.

نیاز فعلی منع اتصال خارجی خود قالب در اجرای معمول، هم از مرورگر و هم از سرور است. فایل لازم از قبل در بسته قابل نصب موجود باشد؛ فعال‌سازی قالب نباید آن را از سرویس ثالث دانلود کند.

**اصلاح مالک در ۲۰۲۶-۱۰-۲۰:** قالب هیچ مسیر دریافت خارجی برای افزونه‌ها ارائه نکند؛ استثنای قبلی نصب Elementor از مخزن لغو شد. Elementor و افزونه‌های ثالث فقط با ZIP محلی مدیر از مسیر استاندارد بارگذاری وردپرس نصب شوند. Core از ZIP محلی همراه Theme نصب/به‌روزرسانی می‌شود؛ [قرارداد نصب](../engineering/plugin-installer.md).

این قاعده خودکار رفتار WordPress، WPML، Elementor/Pro، WP Rocket و سایر افزونه‌های ثالث را تغییر نمی‌دهد؛ آپدیت، لایسنس یا امکانات آن‌ها ممکن است اتصال مستقل داشته باشد. برای هدف «کل سایت بدون هیچ اتصال خارجی»، تنظیمات و نسخه‌های آن‌ها باید جدا بررسی و محدودیت‌ها روشن شوند؛ سازگاری قالب تضمین آفلاین‌بودن همه افزونه‌ها نیست.

**مرز تأییدشده Elementor:** قابلیت خارجی آن فقط در صورت فعال‌سازی صریح همان قابلیت مجاز است؛ صرف نصب/فعال‌بودن افزونه استثنا نیست و قالب نباید اتصال اضافی ایجاد کند. در حالت فونت منتخب رادمان، Google Fonts و منابع فونت خارج از انتخاب محلی مسدود/غیرفعال شوند، حتی در Elementor؛ مرجع کامل در [تایپوگرافی](typography.md). فعال‌سازی صریح سرویس دیگری مانند embed به معنی آزادشدن همه درخواست‌های خارجی نیست. رفتار مستقل آپدیت/لایسنس افزونه باید جدا گزارش شود.

**استثنای صریح مالک — ۲۰۲۶-۱۰-۲۴:** Google Analytics 4 فقط با روشن‌کردن گزینهٔ خودش و شناسهٔ معتبر `G-…` مجاز است؛ فایل Google tag و ارسال دادهٔ همان سرویس اتصال خارجی عمدی‌اند. پیش‌فرض خاموش، بدون fallback و مستقل از Google Fonts است؛ قابلیت‌های عادی قالب همچنان محلی می‌مانند. [سناریوی تنظیمات](settings.md) مالک رفتار و [رابط مدیریت](../engineering/admin-ui.md) مالک جزئیات/شواهد است.

سرویس خارجی دیگری مثل نقشه، ویدئوی embed، ابزار تحلیل دیگر، captcha یا پیام‌رسان فعلاً مجوز اتصال از طرف قالب ندارد؛ اگر خواسته شد، نیاز و استثنای صریح جدا ثبت شود. درگاه پرداخت کلاً خارج از دامنه Radman CT است. Node.js/Vite فقط هنگام توسعه/build استفاده شوند؛ محصول نصب‌شده به Node، API/CDN خارجی یا دانلود وابستگی برای نمایش سایت نیاز نداشته باشد.

## پذیرش پیشنهادی

- در Network صفحه PHP اختصاصی، صفحه Elementor، کاتالوگ، هدر/فوتر و پنل تنظیمات، منشأ هر درخواست مشخص و در حالت پیش‌فرض درخواست خارجی ناشی از Theme/Core صفر باشد؛ با Analytics روشن فقط استثنای صریح همان سرویس مجاز است. درخواست‌های مستقل افزونه‌های ثالث جدا گزارش شوند.
- درخواست‌های سمت سرور نیز بررسی شوند؛ تست مرورگر به‌تنهایی نبود HTTP/DNS خروجی سرور را ثابت نمی‌کند.
- با قطع دسترسی به دامنه‌های خارجی، محتوای اصلی و امکانات محلی قالب کار کنند؛ فونت، کتابخانه یا fallback از کار نیفتد.
- فقط ماژول لازم بارگذاری شود؛ GSAP/افزونه‌های آن تکراری نباشند و صفحه بدون انیمیشن هزینه فایل انیمیشن نگیرد.
- انیمیشن کاهش حرکت، RTL/LTR، موبایل و چرخه preview را رعایت کند؛ listener/timeline تکراری باقی نماند. در ابزار مدیریت React، mount/unmount نیز کنترل شود. انیمیشن مانع دسترسی به محتوا نشود.

## باز

نوع افکت‌های نهایی مشتری، pluginهای اضافه و جزئیات scope اتصال خارجی افزونه‌های ثالث هنوز بازند. موشن عنصر/کانتینر و کامپوننت‌های انتخاب‌شده از ماژول‌ها و import شرطی محلی استفاده می‌کنند؛ مالک نسخه/build در [معماری](../engineering/architecture.md) و [دارایی‌ها](../engineering/assets.md) است. وضعیت و محدودیت اجرا در [شواهد پیاده‌سازی](../implementation/foundation.md) ثبت شده؛ وجود build تأیید سرعت، تمام مرورگرها یا افزونه‌های ثالث نیست.

## مبنای تحقیق

طبق [مستندات رسمی نصب GSAP](https://gsap.com/docs/v3/Installation/)، فایل‌های core و pluginها JavaScript هستند و نصب/بسته‌بندی محلی امکان‌پذیر است؛ CDN الزامی نیست. این موضوع با Context7 بررسی شد؛ شواهد اجرای محدود و فاصله با تأیید سایت واقعی در [وضعیت پیاده‌سازی](../implementation/foundation.md) ثبت می‌شود.
