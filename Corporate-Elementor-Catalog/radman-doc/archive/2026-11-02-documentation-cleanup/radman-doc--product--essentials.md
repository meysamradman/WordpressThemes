# خلاصه پروژه رادمان

هویت تأییدشدهٔ محصول **Radman CT — Corporate & Catalog** است؛ بسته‌های `radmanct`، کلاس‌های `rdct-` و حفظ سازگاری داده طبق [قرارداد نام‌گذاری](../../engineering/naming.md).


وضعیت در ۲۰۲۶-۱۰-۱۹: **پیاده‌سازی تدریجی با درخواست مالک محصول**؛ قالب پایه، Child Theme، پنل، سازنده‌ها و پایهٔ Core با دو ماژول مستقل محصول/نمونه‌کار ساخته شده‌اند؛ انتخاب طراحی اختصاصی/Pro نیز اضافه شده است. همهٔ امکانات و ماتریس افزونه‌ها هنوز تکمیل/تأیید نشده‌اند. [وضعیت و بررسی واقعی](../../implementation/foundation.md).

- محصول: قالب سبک WordPress برای شرکتی، خدماتی، نمونه‌کار و کاتالوگ بدون فروش آنلاین.
- مرجع تصمیم فنی: [معماری قطعی](../../engineering/architecture.md). WordPress/PHP رندر سمت سرور؛ HTML5، Modern CSS، Vanilla JS؛ GSAP + ScrollTrigger اختیاری و محلی؛ Vite برای build.
- React فقط برای مدیریت و Builderهای پیچیده؛ فرانت اختصاصی PHP/HTML و Vanilla JS است. jQuery هسته حذف یا جایگزین نشود و کد اختصاصی رادمان به آن وابسته نباشد.
- محتوای استاندارد با Gutenberg؛ Elementor اختیاری برای صفحه منتخب، بدون وابستگی قالب به نصب آن.
- داده کاتالوگ در افزونه مستقل **Radman CT Content**؛ نمایش در **Radman CT Theme**. ماژول کاتالوگ اختیاری است و قالب بدون آن برای سایت شرکتی کار می‌کند.
- WooCommerce، فروشگاه، سبد و پرداخت کاملاً خارج از Radman CT؛ فروشگاه آینده پروژه جداست.
- اجرای محصول روی هاست معمولی WordPress با PHP/دیتابیس؛ Node.js فقط توسعه/build و بدون سرور Node در هاست مشتری.
- محیط پیشنهادی: PHP 8.3+ و MySQL 8.0+ یا MariaDB 10.11+؛ الزام انحصاری به یک موتور و مسدودسازی بی‌دلیل نسخه‌های قابل پشتیبانی WordPress ممنوع است. جدول پیشنهادی با حداقل فنی/ماتریس آزمون یکی نیست؛ [تصمیم نهایی هاست و دیتابیس](../../engineering/architecture.md).
- طراحی اختصاصی مشتری با کدنویسی آزاد؛ بدون اجبار به طرح آماده یا انتخاب‌گر چندین استایل.
- RTL/LTR، WPML، فونت محلی تحت کنترل قالب، امنیت استاندارد و نبود ثبت‌نام/حساب عمومی اختصاصی همچنان برقرارند.
- عملکرد اولویت اصلی است؛ بررسی محدود اجرا در محیط موقت انجام شده؛ سازگاری کامل افزونه‌ها و سرعت واقعی تأیید نشده‌اند.

## مسیرها و وضعیت واقعی

| مسیر | نقش |
|---|---|
| `radmanct/` | Theme پایه با PHP، source، dist و فونت محلی |
| `radmanct-child/` | Child Theme نمونه برای استایل و صفحات مختص مشتری |
| `radmanct-content/` | افزونهٔ اختیاری مستقل؛ ماژول‌های محصول و نمونه‌کار با دو کلید جدا و دادهٔ ماندگار |
| `radmanct-components/` | افزونهٔ مستقل ضروری قالب برای PHP، ویجت‌های Classic/Atomic، آیکون‌ها و کتابخانه؛ بدون الزام Elementor برای مصرف PHP |
| `radmanct-mcp/` | افزونهٔ اختیاری اتصال عامل با ابزارهای محتوا و ادغام‌های مستقل قالب/Content/Elementor؛ بدون الزام به Content برای وبلاگ/برگه |
| `themes/bridge/`، `themes/hub/` و `themes/woodmart/` و افزونه‌های ارسالی | مرجع مطالعه محدود طبق نقشهٔ مراجع، خارج از بسته و Git |
| `radman-doc/scenarios/` | رفتار محصول |
| `radman-doc/engineering/` | تصمیم فنی و جزئیات پیشنهادی |
| `.agents/skills/` | روش کار agent |

Build/lockfile و ZIP محلی ایجاد شده‌اند؛ بررسی محدود PHP/DB با Elementor/Pro ارسالی انجام شده و نتیجه/هشدارها در [قرارداد Elementor](../../engineering/elementor.md) ثبت است. مرورگر و نصب مشتری تأیید نشده‌اند. برای کار عادی تست کوتاه مرتبط کافی است؛ تست طولانی خودکار اجرا نشود. مخزن مقصد `https://github.com/meysamradman/wp-radman.git`؛ بدون workflow/build/deploy خودکار. stage/commit/push با درخواست صریح کاربر است. پروژه Django با نام مشابه مالک یا وابستگی این پروژه نیست.
