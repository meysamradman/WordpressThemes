# مستندات رادمان

> **آرشیو تاریخی؛ جایگزین‌شده:** این متن مرجع تصمیم جاری نیست. تصمیم قطعی ۲۰۲۶-۱۰-۱۸ در [معماری نهایی](../../engineering/architecture.md) بر تمام وضعیت‌ها و پیشنهادهای این فایل مقدم است. متن قدیمی فقط برای سابقه حفظ شده است.

> **اصلاح نیاز مالک محصول:** قالب بدون افزونه همراه، React در فرانت‌اند، پشتیبانی Elementor و سازنده اختصاصی هدر/فوتر. [اصلاح معماری و نتیجه تحقیق](frontend-direction.md) بر پیشنهادهای ناسازگار قبلی تقدم دارد. جزئیات روش رندر React هنوز انتخاب نشده است.

نسخه: `0.2.0-draft` — تاریخ: ۲۰۲۶-۱۰-۱۸

هدف: قالب مستقل وردپرس با نام **رادمان / Radman** برای سایت شرکتی و کاتالوگ محصولات بدون خرید؛ توسعه مرحله‌ای با امکاناتی که مالک محصول مشخص می‌کند.

این پوشه مرجع گفت‌وگو و تصمیم‌گیری پروژه است. مستندات فعلی طرح پیشنهادی‌اند و کد اجرایی تولید نشده است.

**مرحله فعلی:** فقط گفت‌وگو و ثبت سناریوها؛ پیاده‌سازی شروع نشود. پشتیبانی RTL، LTR و WPML نیاز قطعی محصول است. [سناریوهای چندزبانه](multilingual-scenarios.md).

## وضعیت تصمیم‌ها

- `CONFIRMED`: مالک محصول صریحاً تأیید کرده است.
- `PROPOSED`: پیشنهاد فنی یا محصولی برای بررسی؛ تأییدشده نیست.
- `OPEN`: برای انتخاب به اطلاعات بیشتری نیاز داریم.
- `DEFERRED`: برای مرحله بعد پیشنهاد شده؛ جزو تعهد نسخه اول نیست.

در تعارض با سند اولیه، نیازهای تأییدشده در `requirements.md` ملاک‌اند. پیشنهادهای فنی فقط پس از تصمیم مشترک به `CONFIRMED` تبدیل می‌شوند. تغییر هر تصمیم همراه با دلیل و اثر آن ثبت شود.

## مسیرهای فعلی

- `themes/hub/` و `themes/woodmart/`: نمونه‌های مرجع برای مطالعه؛ وارد بسته رادمان نشوند.
- `radman/`: محل موجود برای قالب؛ فعلاً زیرپوشه‌ها بدون فایل اجرایی هستند.
- `radman-doc/`: مستندات پروژه.

ساخت افزونه، تغییر ساختار پوشه‌ها و راه‌اندازی محیط وردپرس هنوز انجام نشده است.
