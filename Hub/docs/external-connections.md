# اتصال‌های خارجی و بهینه‌سازی محافظه‌کارانه

این گزارش بر اساس کد نسخه تحویل‌شده و یک صفحه نخست تازه در Docker است؛ به معنی
ثبت همه درخواست‌های سایت واقعی یا صفحات طراحی‌شده کاربر نیست. طبق دستور نهایی،
غیر از حذف لایسنس هیچ محدودکننده شبکه یا تغییر بهینه‌سازی روی قالب اعمال نشده است.
استثنای جدیدِ مورد تأیید کاربر، بازگرداندن اعلان آپدیت قالب به‌صورت کش‌شده است؛
updater در صفحات معمولی به شبکه وصل نمی‌شود و از قفل لایسنس مستقل است.

## CSS و JavaScript اصلی

مسیر اصلی asset manager در `hub/theme/liquid-scripts.php`، منابع `hub/assets/` و
دارایی‌های `hub-elementor-addons/assets/` از همان نصب سرو می‌شوند. نیاز به تبدیل
سراسری به CDN یا جایگزینی کتابخانه‌های اصلی نیست. در HTML صفحه نخست تازه آزمایشی،
script یا stylesheet خارجی دیده نشد؛ آدرس gmpg.org صرفاً لینک profile در head بود،
نه فایل CSS/JS دانلودشونده. این نتیجه شامل صفحات دیگر، iframe و درخواست‌های runtime JS نیست.

فایل‌های CSS/JS ساخته‌شده در `uploads/liquid-styles/` هم محلی هستند. گزینه‌های
`enable_optimized_files` و `combine_js` موجودند، ولی به علت ترتیب وابستگی‌ها و
ویرایشگر، روشن‌کردن کورکورانه همه گزینه‌های combine/defer توصیه نمی‌شود. در این
نوبت تنظیمات تغییر نکردند و ادعای افزایش سرعت مطرح نیست.

## مورد مشاهده‌شده در بررسی کوتاه ویرایشگر

Elementor 4.3.5 در فایل `elementor/core/editor/loader/editor-loader.php:272,278`
دو فایل ACE 1.43.2 را از `cdn.jsdelivr.net` می‌گیرد. در تلاش مرورگری این محیط،
`ace.min.js` معطل ماند؛ فایل language tools پاسخ ۲۰۰ داد و ویرایشگر هنوز Loading بود.
این اتصال مربوط به ویرایشگر Elementor است، نه CSS/JS صفحه نخست یا Hub Collections.
برای کاهش وابستگی شبکه می‌توان در یک اصلاح مستقل همین نسخه فایل‌ها را محلی کرد
و از hook رسمی منبع اسکریپت استفاده کرد؛ در این نوبت اجرا نشده است. نمایش صحیح
کنترل کد و پنجره کتابخانه پس از چنین اصلاحی باید کوتاه و واقعی بررسی شود.

به‌روزرسانی مشاهده همان روز: پس از انتقال runtime به volume و اصلاح permissions،
در اجرای بعدی هر دو فایل ACE پاسخ ۲۰۰ گرفتند و کتابخانه اصلی با ۱۰۶۰ طرح باز شد.
پس معطل‌بودن CDN در تلاش قبلی مشاهده شده بود، نه یک خرابی دائمی اثبات‌شده.
هیچ فایل ACE یا آدرس CDN در کد تغییر نکرد.

## ترتیب پیشنهادی برای مرحله بعد

1. فونت دقیق همان طراحی را با وزن‌های لازم محلی کن؛ Google Fonts قالب و Elementor
   پس از انتخاب جایگزین محلی خاموش شود. `font-display: swap` حفظ شود.
2. اگر از Local Fonts خود Hub استفاده می‌کنی، ابتدا cache پایدار CSS، پشتیبانی css2،
   timeout و fallback فایل موجود به‌صورت مستقل اصلاح شوند؛ فعلاً صرف روشن‌کردن آن
   را راهکار قطع اتصال تکراری حساب نکن.
3. کلید Maps و multicurrency و feedهای بدون استفاده خاموش شوند؛ کتابخانه مستثنا بماند.
4. در یک صفحه واقعیِ طراحی‌شده، درخواست‌های Network ثبت شود؛ سپس فقط موارد واقعاً
   مشاهده‌شده اصلاح شوند. محتوای دیتابیس و افزونه‌های دیگر در audit کد این پوشه پوشش ندارند.

آپدیت‌های خود WordPress و Elementor نیز اتصال‌های مستقل خود را دارند و با حذف
لایسنس Hub قطع نمی‌شوند. در این نوبت دست‌کاری نشده‌اند.
