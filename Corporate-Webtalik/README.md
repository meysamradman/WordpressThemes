# Radman CT — Custom PHP

قالب شرکتی و نمونه‌کارِ سفارشی با PHP، Vanilla JS و GSAP؛ مستقل از نسخهٔ عمومی Corporate-Catalog و بدون Elementor. سایت فعلی وبتالیک است. قرارداد نام‌گذاری در [docs/naming.md](docs/naming.md)، معماری در [docs/architecture.md](docs/architecture.md) و قرارداد WordPress و دیتابیس در [docs/wordpress.md](docs/wordpress.md) است؛ [docs/remaining.md](docs/remaining.md) فقط کارهای باز را نگه می‌دارد.

- شروع: `WordPress-Start.cmd`؛ توقف بدون حذف داده: `WordPress-Stop.cmd`
- سایت: http://127.0.0.1:8095/ ؛ مدیریت: http://127.0.0.1:8095/wp-admin/
- مشخصات ورود: `artifacts/local-wordpress-access.txt`؛ فقط محلی و خارج از Git.
- build: `npm run build`؛ Node فقط ابزار توسعه است.
