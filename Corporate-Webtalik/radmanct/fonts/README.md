# Local font sources

PeydaWebVF.woff2 and Hafez-FD-Regular.woff2 are the existing owner-supplied font files copied from Corporate-Catalog/radmanct/fonts/persian. This project does not grant additional font licensing rights. Preserve the original provenance and owner licensing when deploying or redistributing. Vite generates hashed runtime copies; preloads must use the same manifest URL as CSS.

Canonical font files live only in this directory. Build references them without copying into dist; font-face is defined once in src/css/tokens.css.
