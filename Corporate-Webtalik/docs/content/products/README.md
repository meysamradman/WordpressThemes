# محصولات وب‌تالیک

**وضعیت** · بستهٔ مستقل [محصولات ۱.۲](reference-v1.2/README.md) مرجع پیشنهادی طراحی و نگارش است. هاب و هر سه لندینگ در مرحلهٔ بازبینی‌اند. پس از تأیید مالک، همین بسته جایگزین پیشنهادهای محصول در نسخه‌های ۱.۴ و ۱.۵ می‌شود. وضعیت هر صفحه پیش از اجرا و انتشار در [دفتر تصمیم‌ها](../DECISION-REGISTER.md) ثبت شود.

**مدل ارائه** · مشتری نسخه‌ای متناسب با کسب‌وکارش را بر پایهٔ هستهٔ موجود سفارش می‌دهد. تنها اقدام تجاری لندینگ «ثبت سفارش اختصاصی» است. «مشاهده جزئیات» در کارت هاب برای ناوبری است. قیمت و زمان پس از تعیین محدوده توافق می‌شوند. سایت شرکتی وبتالیک برای این مسیر حساب اجباری، سبد خرید و پرداخت ندارد. پرداخت احتمالی متعلق به نسخهٔ فروشگاهی مشتری است.

## جایگاه پنل مدیریت

[پیش‌نویس مستقل پنل در ۱.۵](../reference-v1.5/14-product-admin-panel.md) در وضعیت توقف انتشار است. نمونهٔ React و Vite در [خدمت طراحی پنل مدیریت و سامانه‌های تحت وب](../services/web-systems.md) فقط با شواهد تأییدشده استفاده می‌شود. در بستهٔ محصولات، پنل فروشگاه یک سکشن در [لندینگ فروشگاه](reference-v1.2/02-product-ecommerce.md) است. شناسهٔ `store-admin-panel` پیشنهادی است و لینک خدمت پس از تأیید HTML و انتشار مقصد فعال می‌شود.
