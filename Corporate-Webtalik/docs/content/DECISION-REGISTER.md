# دفتر تصمیم‌های وب‌تالیک

این دفتر وضعیت تصمیم‌های بین چند سند را ثبت می‌کند. متن صفحه، دادهٔ تماس، آمار مبنا و URLهای موردی در سند مالک باقی می‌مانند. تصمیم باز، پیشنهاد یا مشاهدهٔ لوکال را با تأیید انتشار یکی نگیریم.

## تصمیم‌های تثبیت‌شده

| تصمیم | مرجع |
| --- | --- |
| نام عمومی «وبتالیک / Webtalik» و شناسه‌های سازگار قالب | [نام‌گذاری](../naming.md) |
| چهار خدمت مستقل و محصولات آمادهٔ قابل سفارشی‌سازی با لندینگ معرفی و درخواست | [خدمات](services/README.md) · [محصولات](products/README.md) |
| بخش فناوری‌های توسعهٔ وب‌سایت اختصاصی با سه ردیف استیکی | [شناسنامه](services/custom-website/scenario.md) |
| متن نهایی پنج مرحلهٔ اجرای وب‌سایت اختصاصی با خروجی هر مرحله | [متن‌های صفحه](services/custom-website/copy.md) |
| بستهٔ ۱.۲ مرجع پژوهش و پیش‌نویس خدمات است. شناسنامه‌های فعال مالک مسیر، وضعیت متن و تعریف خدمت چهارم هستند. | [راهنمای خدمات](services/README.md) |

| انتقال روی همان دامنه. فروش دوره و خدمت تیزر در منوی جدید قرار نمی‌گیرند | [مهاجرت](migration.md) |

| اولویت | مورد | وضعیت یا شرط تصمیم |
| --- | --- | --- |
| P0 | مسیر نهایی آرشیو نمونه‌کار | `/projects/` مسیر فعلی قالب و نامزد انتقال است. `/portfolio/` پیشنهاد قدیمی است. تصمیم URL پس از تأیید مالک و بررسی rewrite و نگاشت مستقل پروژه‌ها. [نقشهٔ انتقال](migration-urls.md) |
| P0 | URLهای نهایی سه محصول | مسیرهای فعلی محلی ثبت شده‌اند. Slug، هم‌خوانی H1 و SEO Title و مقصد نهایی پیش از انتشار تأیید شوند. [محصولات](products/README.md) |
| P0 | موجودی URL و ریدایرکت‌ها | خروجی وردپرس، Search Console، Sitemap و بک‌لینک‌ها تلفیق شوند. جدول فعلی اولیه است. [نقشهٔ انتقال](migration-urls.md) |
| P1 | محتوای «درباره ما» و مسیر نهایی | بریف ۱.۳ برای تطبیق با طرح ثبت شده است. متن عمومی، شواهد سابقه و تیم، و تصمیم حفظ یا انتقال مسیر قدیمی پس از بازبینی ثبت شوند. [شناسنامهٔ صفحه](pages.md#about-us) |
| P1 | جایگاه و عرضهٔ پنل مدیریت وبتالیک | بستهٔ ۱.۴ برای تطبیق با طراحی ثبت شد. محصول، دمو یا نمونه‌کار بودن پنل، نام نهایی، مسیر و شواهد قابلیت‌ها پیش از معرفی عمومی تعیین شوند. [شناسنامهٔ محصولات](products/README.md#admin-panel) |
| P0 | دوره و دسترسی خریداران | وضعیت سفارش تاریخی، دسترسی و دانلود و پاسخ URLها قبل از خاموش‌کردن فروش قدیمی تعیین شود. [مهاجرت](migration.md) |
| P1 | متن و شواهد خدمات و محصولات | هیرو، رویکرد و گرید ویژگی‌های خدمت اول اعمال شده‌اند. سایر متن‌های پیشنهادی آن در بازبینی‌اند. سه خدمت دیگر و سه محصول به شواهد واقعی، رسانهٔ قابل انتشار و تأیید متن کامل نیاز دارند. |
| P1 | دادهٔ سئو و Sitemap قدیمی | خط مبنای قبلی ثبت شده. علت وضعیت `Couldn't fetch` و بازهٔ گزارش با خروجی تازه و HTTP بررسی شوند. [مهاجرت](migration.md) |
| P1 | وبلاگ و نمونه‌کار | موجودی کامل، شباهت موضوع مقاله‌ها و رسانه و پروژه‌های قابل انتشار تعیین شود. [وبلاگ](blog.md) · [نمونه‌کارها](portfolio.md) |
| P1 | تصویر Cover برگه‌های داخلی | اختلاف منبع پیش‌فرض فعلی با قرارداد رسانه در [کارهای باقی‌مانده](../remaining.md) ثبت شده. |
| P1 | پروفایل Hub در استانداردهای مشترک | بندهای Hub در [GSAP](../../../WEB-DEVELOPMENT-STANDARDS/shared/05-GSAP-ANIMATION-STANDARD-v1.1.md) و [Elementor](../../../WEB-DEVELOPMENT-STANDARDS/wordpress-elementor/15-WORDPRESS-ELEMENTOR-DEVELOPMENT-v1.0.md) وجود دارند. انتقال هر استثنا به سند پروژهٔ مالک نیازمند بازبینی همان پروژه و حفظ رفتار تأییدشده است. |
| P2 | شیوهٔ مدیریت محصولات | صفحات معرفی فعلی مبنا هستند. انتخاب Page یا نوع محتوای مستقل پس از شناخت نیاز ویرایش و نگاشت URL انجام می‌شود. [محصولات](products/README.md) |

هنگام تأیید یک تصمیم باز، نتیجه، تأییدکننده، تاریخ و پیوند سند مالک ثبت شود. نتیجهٔ تست فقط بعد از مشاهدهٔ واقعی درج شود.
