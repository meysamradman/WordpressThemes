# کپی لوکال فروشگاه دارویی

- نشانی بازدید `http://127.0.0.1:8099/` و پروژهٔ Docker با نام `darooyi` است. MySQL داخلی به‌صورت جداگانه در volume `darooyi_db` و فایل‌های قابل‌ویرایش وردپرس در `darooyi_site` قرار دارند.
- ورودی‌ها `public_html/` و `darooyic_wpdb.sql` هستند. Docker آن‌ها را فقط برای خواندن برمی‌دارد. راه‌اندازی، تنظیم اتصال محلی و نگاشت نشانی‌ها در کپی کار انجام می‌شوند. حساب‌های وردپرس همان داده‌های بکاپ‌اند.
- از همین پوشه `docker compose up -d` برای روشن‌کردن و `docker compose stop` برای توقف استفاده کنید. گزینهٔ حذف volume را هنگام توقف انتخاب نکنید. فایل خصوصی `.env` باید با volume دیتابیس بماند.
- سرویس فقط روی رایانهٔ محلی منتشر می‌شود. نسخهٔ آزمایشی پرداخت، پیامک، ایمیل و کارهای زمان‌بندی‌شده را به سرویس واقعی نمی‌فرستد. پس از تأیید تغییرات، فایل‌ها و داده‌های لازم برای دامنهٔ اصلی در تحویل جداگانه آماده می‌شوند.

وردپرس ۷.۱.۵ و قالب WoodMart از فایل‌های مشتری بارگذاری می‌شوند. PHP 8.3 با Loader رسمی ionCube برای افزونهٔ Digits و MySQL 8.4 اجرا می‌شود. فایل‌های کمکی `.local/wp-cli.phar` و `.local/ioncube_loader_lin_8.3.so` برای همین محیط محلی‌اند. Elementor Pro مطابق بکاپ نصب و غیرفعال است.

به‌روزرسانی دستی و نصب افزونه از مخزن WordPress.org و بارگذاری ZIP از پیشخوان امکان‌پذیر است. سرویس داخلی `plugin-repository` فقط API و بسته‌های رسمی افزونه را می‌گیرد. [راهنمای Digits و مجوز محیط آزمایشی](docs/digits.md)
