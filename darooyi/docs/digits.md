# Digits در محیط محلی دارویی

Digits ورود و ثبت‌نام با موبایل را مدیریت می‌کند. نسخهٔ برگرفته از بکاپ مشتری با Loader رسمی ionCube برای PHP 8.3 اجرا می‌شود. فایل‌های افزونه و تنظیمات مجوز از بکاپ حفظ شده‌اند. مجوز فعال دامنهٔ اصلی ممکن است نصب مستقل روی لوکال یا دامنهٔ آزمایشی را پوشش ندهد. [ionCube Loader](https://www.ioncube.com/loaders.php) · [مستندات رسمی ژاکت](https://zhaket.github.io/guard/)

## نسخهٔ جدید افزونه

1. بسته را از حساب خرید مشتری یا فروشنده دریافت کنید. نسخهٔ فعلی Digits، نسخهٔ PHP و نیاز ionCube را قبل از به‌روزرسانی ثبت کنید.
2. برای آزمایش ورود با پیامک، از فروشندهٔ همین محصول دربارهٔ مجوز محیط آزمایشی یا امکان استفاده در لوکال استعلام کنید. تغییر فعال‌سازی دامنهٔ اصلی را جداگانه و با تأیید مالک انجام دهید.
3. روی کپی Docker از دیتابیس بکاپ بگیرید و بستهٔ رسمی را از «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب کنید. وضعیت مجوز را از خود پنل افزونه بررسی کنید. ورود مدیر و فرم‌های حساب و تسویه را قبل از بسته‌بندی بازبینی کنید.
4. آزمایش پیامک را با تنظیمات آزمایشی و شمارهٔ تست انجام دهید. کلید مجوز یا اطلاعات سرویس پیامک در مستندات و خروجی عمومی قرار نمی‌گیرد.

فهرست و آپدیت افزونه‌های WordPress.org از سرویس داخلی پروژه می‌گذرد. این سرویس فقط API و بسته‌های رسمی افزونه‌ها را می‌گیرد. دسترسی ژاکت، پیامک و پرداخت مسیرهای جداگانه‌اند.
