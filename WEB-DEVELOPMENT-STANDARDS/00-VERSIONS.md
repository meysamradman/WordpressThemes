# نسخه‌های مهم پروژه‌ها

> بازبینی بسته 1.3 — 2026-11-19؛ نام مسیر برای سازگاری ارجاع‌های موجود حفظ شده است. تاریخچه در CHANGELOG-v1.3.md.

نسخه‌های این صفحه مبنای شروع کار هستند. برای طراحی، مستندسازی یا اصلاح معمول لازم نیست هر بار نسخه‌ها دوباره جست‌وجو شوند. در تغییر API، ارتقا، خطای ناسازگاری، ساخت برای هاست تازه یا تغییر محیط، فقط عدد مربوط به همان کار از منبع اصلی کنترل شود.

| کاربرد | ویبتالیک | علی اسدی | Elementor Catalog |
|---|---|---|---|
| نسخهٔ قالب و حداقل اعلام‌شده | قالب 1.1.1، WordPress 6.6، PHP 8.0 | قالب 1.1.1، WordPress 6.6، PHP 8.0 | قالب 1.1.1، WordPress 6.6، PHP 8.0 |
| مبنای محلی | WordPress 7.1.4، PHP CLI 8.4.26، MySQL 8.4.13 | WordPress 7.1.4، PHP CLI 8.4.26، MySQL 8.4.13 | Compose با خانوادهٔ PHP 8.4 و MariaDB 11.4. نسخهٔ دقیق نصب فعلی در این بررسی مشاهده نشد. |
| ابزار ساخت | Node ≥22.12.0 در manifest، Vite 8.3.4، GSAP 3.15.0 | همان نسخه‌ها | همان نسخه‌ها برای مخزن فعلی |
| Elementor / Pro | خارج از مسیر پروژه | خارج از مسیر پروژه | بررسی تاریخی مشخص با Elementor 4.3.5، Pro 4.3.2 و WordPress 7.1.3 ثبت شده است. این اعداد نسخهٔ نصب فعلی یا تضمین همهٔ ویجت‌ها نیستند. |

مشاهدهٔ محیط‌های سفارشی در **2026-11-18** انجام شد. حداقل header دامنهٔ پشتیبانیِ آزموده را تعیین نمی‌کند. برای توسعهٔ جدید، PHP 8.4+ هدف عمومی است. PHP وب و دیتابیس هاست، نسخهٔ core، افزونه‌ها و کش انتشار بر اساس محیط همان مشتری ثبت می‌شوند.

**منبع به‌روزرسانی** برای نسخهٔ قالب و حداقل‌ها `style.css`، برای ابزارها `package.json` و lockfile، برای محیط `compose.yaml` و خروجی واقعی اجرا، و برای افزونه‌ها header بستهٔ نصب‌شده است. در تغییر واقعی نسخه، فقط جدول مربوط و تاریخ تأیید را اصلاح کنید.
